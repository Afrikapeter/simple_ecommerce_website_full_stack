# simple_ecommerce_website_full_stack
This is a simple Ecommerce website for agricultural grains store shop
Purpose of this website: To facilitate the purchasing of grains and other agricultural products for home uses as food so as to save time of house owner on searching place of getting the quality grain at affordable price.

Front-end plan: i) The website will have single landing page with three main sections as header, welcome instruction, Shopping section(main body), and Tail(Shop physical address and more details).
ii)Main body will be made from table with pictures of products and stock availability.
iii)Header will have Home button, cart items button, and user account button.
iv) website color will have green and dark blue with text font color of white and black.

Back-end plan: i) Handling add to cart functions like adding items, removing items, delete items and updating to user if the request number of items is available in stock.
ii) Handling data base for stock management to user and admin.
iii) Handling checkout and facilitating online payment API.
